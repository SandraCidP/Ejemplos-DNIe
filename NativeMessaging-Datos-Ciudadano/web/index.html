Los certificados incluyen nombre y DNI: el programa pedirá permiso. Las claves públicas no.
El programa enseña el texto, pide confirmación y el PIN.

El archivo se elige en una ventana de Windows; la página solo recibe su nombre y la firma.

Es una firma «en bruto» del SHA-256 del archivo (ECDSA r||s con el DNIe 4.0, PKCS#1 v1.5 con el DNIe 3.0), no un formato de firma de documentos (CAdES, PAdES o XAdES). Para firmar documentos con esos formatos, use AutoFirma.
