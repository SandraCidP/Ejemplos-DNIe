ENTREGA EJEMPLOS DE CÓDIGO DEL DNIe 1.0 PARA WINDOWS - 27/11/2026
Equipo DIT Drivers - FNMT-RCM (dit.drivers@fnmt.es)

CONTENIDO
- ActiveX-Datos-Ciudadano\              Control ActiveX para leer los datos del ciudadano (datos personales, MRZ,
                                        foto y firma manuscrita) y los certificados del DNIe, y para firmar con él.
                                        Misma interfaz que el ActiveX publicado en el portal del DNIe.
                                        Para Internet Explorer 11, Edge en modo Internet Explorer y aplicaciones HTA.
- ActiveX-Firma-Verificacion\           Control ActiveX para firmar archivos con el DNIe y verificar firmas.
                                        Para Internet Explorer 11, Edge en modo Internet Explorer y aplicaciones HTA.
- NativeMessaging-Datos-Ciudadano\      Lectura de los datos del ciudadano y firma, para Chrome, Edge y Firefox
                                        (programa, extensión del navegador y página de ejemplo).
- NativeMessaging-Firma-Verificacion\   Firma de archivos y verificación de firmas, para Chrome, Edge y Firefox
                                        (programa, extensión del navegador y página de ejemplo).

Cada proyecto incluye el código fuente, los binarios compilados y firmados, una página de ejemplo
y la guía para desarrolladores (carpeta docs, en Markdown y en PDF).

REQUISITOS
- Windows 10 u 11, un lector de tarjetas y un DNIe 3.0 o 4.0.
- Ejemplos de lectura de datos: driver PKCS#11 del DNIe para Windows (2.0.0.13 o posterior).
- Ejemplos de firma y verificación: middleware del DNIe para Windows (Card Module).

NOTAS
